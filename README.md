# 🎵 Music Web App (Apple Music Style Offline Web Player)

Автономный веб-плеер в стиле Apple Music (PWA), работающий без интернета прямо в браузере.

## 🚀 Возможности
- **Стиль Apple Music / iOS**: минималистичный интерфейс, темная тема, плавный мини-плеер и полноэкранный плеер.
- **Офлайн-режим (100% offline)**: музыка и обложки сохраняются в IndexedDB браузера. Работает без интернета и в авиарежиме.
- **Фоновое воспроизведение**: полная поддержка системного управления воспроизведением (MediaSession API — экран блокировки, шторка, наушники).
- **Импорт музыки**:
  - Кнопка **«Добавить музыку»** (выбор файлов/папок с авточтением ID3-тегов: название, артист, альбом, обложка).
  - Вкладка **«Поиск»** (поиск в открытых аудиоколлекциях + сохранение по прямой ссылке).
- **Сортировка**: по трекам, альбомам, артистам и избранному.

## 📦 Локальный запуск
```bash
npm install
npm run dev
```

## 🌐 Публикация на GitHub Pages
1. Создайте репозиторий на GitHub.
2. В файле `vite.config.ts` укажите название вашего репозитория (если сайт разворачивается не на домене верхнего уровня):
   ```ts
   base: '/<название-репозитория>/',
   ```
3. Запушьте код в ветку `main`:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ваш-аккаунт>/<название-репозитория>.git
   git push -u origin main
   ```
4. В настройках репозитория на GitHub перейдите в **Settings → Pages** и в пункте **Build and deployment → Source** выберите **GitHub Actions**.
5. Сайт автоматически соберется и станет доступен по ссылке `https://<ваш-аккаунт>.github.io/<название-репозитория>/`.
